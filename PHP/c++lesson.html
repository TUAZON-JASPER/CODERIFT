Lesson 1: Introduction to C++

C++ is a powerful, high-performance programming language that supports multiple programming paradigms, including procedural, object-oriented, and generic programming. It was created by Bjarne Stroustrup in the early 1980s as an enhancement to the C language. C++ is widely used for system/software development, game programming, and applications requiring real-time performance.

  • Key Features:
    • Compiled language for faster execution.
    • Strongly typed with a rich set of data types.
    • Support for low-level memory manipulation.
    • Extensive standard library.
  • File Extension: The standard file extension for C++ source code is .cpp.

Lesson 3: Variables in C++

Variables are used to store data in a program. Each variable must be declared with a specific data type before it can be used, indicating what kind of data it can hold.

  • Correct Declaration: The correct way to declare an integer variable is int x;.
  • Example:
    int age = 30; // Declaration of an integer variable float height = 5'9; // Declaration of a floating-point variable char initial = 'A'; // Declaration of a character variable
Lesson 4: Data Types

C++ supports various data types that define the type of data a variable can hold. Common data types include:

  • int: Whole numbers (e.g., int score = 100;)
  • float: Floating-point numbers (e.g., float temperature = 36.6;)
  • double: Larger floating-point numbers (e.g., double pi = 3.14159;)
  • char: Single characters (e.g., char letter = 'Z';)
  • bool: Boolean values (true/false).
  • Floating-Point Keyword: The keyword used to declare a floating-point variable is float.
  • Example:
    float average = 85.5; // Declare a floating-point variable
    • Lesson 5: Operators

    Operators in C++ are symbols used to perform operations on variables and values. Types of Operators


    Arithmetic Operators: Perform basic math operations.
    Example: +, -, *, /, %

    Relational Operators: Compare values.
    Example: ==, !=, >, <, >=, <=

    Logical Operators: Combine conditions.
    Example: &&, ||, !

    Assignment Operators: Assign values to variables.
    Example: =, +=, -=, *=, /=, %=

    Increment/Decrement Operators: Increase or decrease variable values by one.
    Example: ++, --

    Bitwise Operators: Perform operations on binary numbers.
    Example: &, |, ^, <<, >>

    Ternary Operator: Conditional operator.
    Example: condition ? value_if_true : value_if_false

    Example:
    • Arithmetic: int result = 10 + 5;
    • Relational: bool is_equal = (10 == 5);
    • Logical: bool logical_result = (true && false);
    • Assignment: int x = 10; x += 5;
    • Increment/Decrement: int y = 5; y++;
    • Bitwise: int z = 3 & 6;
    • Ternary: int max_num = (a > b) ? a : b;
  • Usage: Operators are essential for calculations, comparisons, and logical operations in C++. They manipulate variables and control program flow efficiently.

    • Switch Statement: The keyword used to handle multiple cases in a switch is case.
    • Example:
      int number = 15;
      if (number > 0) {
      cout << "Positive number";
      } else if (number < 0) {
      cout << "Negative number";
      } else {
      cout << "Zero";
      }
